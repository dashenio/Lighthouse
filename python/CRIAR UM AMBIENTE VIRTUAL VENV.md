### Criar um ambiente virtual VENV

1. python -m venv .venv
2. source .venv/Scripts/activate (ativa o ambiente)
3. pip install nome\_do\_pacote
4. deactivate

#### 

## Importar módulos

1. python
2. import nome\_do\_pacote
3. OU from nome\_do\_pacote import nome\_funcao - importa apenas uma função



Modulos úteis: math, os, json, pandas, numpy, requests, datetime
